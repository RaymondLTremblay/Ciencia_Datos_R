10.1 Funciones en este módulo

-   mutate() # crea nuevas variables
-   transmute() # crea nuevas variables y elimina las antiguas
-   lag() # calcula la diferencia entre valores en la misma columna
-   lead() # calcula el siguiente valor en un vector
-   cumsum() # suma cumulativa
-   cummean() # promedio cumulativo
-   cumvar() # varianza cumulativa

mutate() y transmute(): crear columnas nuevas.

  • mutate(nueva = expresión): añade columnas calculadas y conserva las demás.
  • transmute(): igual, pero solo deja las columnas nuevas.
  • Uso: la expresión puede combinar otras columnas (p. ej. velocidad = distancia / tiempo).

10.5 lag()

lag() y lead(): valor anterior / siguiente.

  • lag(x, n): trae el valor de n filas atrás (por defecto 1); útil para calcular cambios (x - lag(x)).
  • lead(x, n): trae el valor de n filas adelante.
  • Requisito: ordena las filas primero (arrange()), porque operan según el orden actual.
