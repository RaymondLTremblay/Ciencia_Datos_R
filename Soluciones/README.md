# Soluciones (uso del profesor)

Esta carpeta contiene las respuestas de referencia de los ejercicios de cada
capítulo del libro.

- **No forma parte del libro publicado.** `bookdown` solo construye los archivos
  listados en `rmd_files:` dentro de `_bookdown.yml`, y ninguno de estos archivos
  está en esa lista.
- Los ejercicios viven en el capítulo correspondiente (en cajas `::: {.ejercicio}`)
  y **sin el script de solución**, para que el estudiante escriba su propio código.
- Un archivo por capítulo, con el mismo número del archivo del capítulo:
  `09-Soluciones-Transformacion-mutate.Rmd` corresponde a
  `09-Transformacion-mutate.Rmd`.
